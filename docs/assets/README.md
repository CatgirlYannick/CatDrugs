# Asset Sources and Processing

Updated: 2026-08-11

The source PNG files were created with the built-in image-generation workflow,
then processed with nearest-neighbor scaling and chroma-key removal into the
final transparent CatItems assets.

This directory contains the source atlases, previews, pharmacist sources, and
the public CatDrugs project icon. Runtime-ready assets are stored under
`catitems-addon/assets/` and embedded in the CatDrugs JAR.
