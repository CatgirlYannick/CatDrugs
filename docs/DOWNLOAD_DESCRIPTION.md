# CatDrugs 0.8.2 Alpha

CatDrugs turns fictional survival substances into a configurable Paper gameplay
system. Ninety consumables use staged effects, persistent tolerance and
dependence, withdrawal and recovery, mixed-category risks, dose reactions, and
safe blackout recovery.

Survival content includes fantasy recipes, structure loot, cultivation drops,
a portable alchemy lab, village pharmacists, dealer reputation, quests, tokens,
patrol encounters, random supply finds, and an antidote-based player rescue
interaction. Every production path is intentionally fictional and does not
describe real-world procedures.

CatDrugs has no required plugin dependency. It remains fully playable with
Vanilla items. The optional CatItems integration installs custom definitions,
textures, models, and a pharmacist appearance into one shared resource pack.

## Requirements

- Java 21
- Paper 1.21 through 1.21.11
- Optional: CatItems for custom visuals

## Important

This is an Alpha build. Back up your server, review every generated config, and
test balance and integrations before production use. Replace the JAR only while
the server is stopped, then perform a full Paper start.
